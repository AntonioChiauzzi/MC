Agricultural Digital Twin (Mirroring System)
Sistema in UE5/C++ per il mirroring in tempo reale di un ambiente agricolo

Requisiti minimi:
-Unreal Engine 5.x
-Visual Studio 2022 (Workload: "Sviluppo di giochi con C++)

Come funziona:
-Download della repository
-Tasto destro su file .uproject > Generate Visual Studio project files

Il progetto utilizza file JSON per il salvataggio delle entità spawnate e delle variabili di ambiente, questi JSON sono situati nel percorso
"MC/Content/Data/entities.json" e "MC/Content/Data/environment.json"
